# حسابات التجربة وسيناريو تجربة المستخدم الكاملة

> حسابات **تجريبية فقط** على جهاز التطوير. لا تستخدمها في نسخة منشورة على الإنترنت.
> تُنشأ أو تُستعاد بالأمر: `python manage.py seed_demo`

افتح التطبيق: http://127.0.0.1:8000 — كلمة المرور لكل الحسابات: **`Strong@123`**

## الحسابات

| الدور | اسم المستخدم | ماذا يميّزه |
|---|---|---|
| مشرف | `admin` | المستخدمون، توثيق الأطباء، دليل الأطباء، سجل العمليات، لوحة الإحصاءات |
| طبيب | `dr.samer` | د. سامر حسن — أمراض داخلية — **يحتاج موافقة** على الحجز |
| طبيب | `dr.rania` | د. رانيا يوسف — أمراض القلب — **يحتاج موافقة** |
| طبيب | `dr.khaled` | د. خالد العمر — الأمراض الصدرية — **تثبيت فوري** بدون موافقة |
| ممرضة | `nurse.lina` | مخصّصة لأطباء الدليل المشتركين، تستقبل طلباتهم وتوافق عليها |
| ممرضة | `nurse.huda` | غير مخصّصة لأي طبيب، فترى كل المواعيد |
| مريضة | `patient.nour` | ملف كامل: سكري، ربو، تحسس من البنسلين، أدوية، عملية سابقة |
| مريض | `patient.omar` | ملف شبه فارغ — لتجربة إضافة البيانات من الطبيب |
| مريضة | `patient.maya` | لتجربة حجز نفس الوقت من مريضين |

**نصيحة:** لتجربة دورين معاً افتح نافذة عادية ونافذة خاصة (Incognito)، أو استخدم `localhost:8000` في واحدة و `127.0.0.1:8000` في الأخرى؛ كل عنوان له جلسة دخول مستقلة.

## سيناريو التجربة الكاملة (حوالي 20 دقيقة)

### 1. المريض: الهوية والسجل
1. ادخل بـ `patient.nour` ← شاهد بطاقة الهوية الطبية (زمرة الدم، رقم الهوية، التحسس باللون الأحمر).
2. افتح **سجلي الطبي** ← لاحظ أنه للقراءة فقط.
3. من **حسابي** عدّل رقم الهاتف ← هذا الحقل الوحيد المسموح للمريض مع البريد والعنوان.

### 2. الدليل الصحي الذكي
1. افتح **الدليل الصحي** واكتب: `عندي سعال وبلغم من أسبوع مع ضيق خفيف بالنفس`.
2. أجب عن الأسئلة ← ستظهر النتيجة: الأمراض الصدرية + تحاليل مقترحة.
3. اضغط **احجز مع طبيب الأمراض الصدرية** ← يظهر `dr.khaled`.
4. جرّب حالة طارئة: `ألم صدر شديد وضيق تنفس شديد` ← نتيجة فورية بزر الإسعاف 110.

### 3. الحجز مع تثبيت فوري
1. احجز مع `dr.khaled` ← يتثبّت الموعد مباشرة ويصل إشعار "تم تثبيت موعدك".

### 4. الحجز مع موافقة (الدورة الأساسية)
1. بـ `patient.nour` احجز مع `dr.samer` وقتاً معيّناً ← الحالة "بانتظار الموافقة".
2. بنافذة ثانية ادخل بـ `patient.maya` وافتح نفس الطبيب ونفس اليوم ← **الوقت مشطوب ولا يمكن حجزه**.
3. ادخل بـ `dr.samer` ← الطلب في لوحة التحكم مع ملخص الدليل الصحي (إن حجزت من الدليل) ← **موافقة**.
4. ارجع لـ `patient.nour` ← خلال 30 ثانية يظهر الإشعار والموعد صار "مؤكد".
5. كرّر الحجز ثم ادخل بـ `nurse.lina` وارفض الطلب مع سبب ← المريض يرى السبب، والوقت يعود متاحاً.

### 5. الطبيب
1. بـ `dr.samer` افتح **أوقات الدوام والإعدادات** ← غيّر الدوام، أضف يوم إجازة، بدّل بين "يحتاج موافقة" و"تثبيت فوري".
2. افتح **التقويم** ← اضغط على موعد لإدارته، أو على خانة فارغة لإضافة موعد لمريض.
3. افتح **المرضى** ← `patient.omar` ← أضف مرضاً مزمناً، تحسساً، دواءً، وارفع ملف PDF.
4. في نفس الصفحة جرّب **المساعد السريري**: "هل توجد تداخلات دوائية أو تحسسات مهمة؟" (مع `patient.nour`).
5. سجّل مريضاً جديداً من زر **مريض جديد** مع حساب دخول ← جرّب الدخول به.

### 6. تسجيل طبيب جديد وتوثيقه
1. من صفحة الدخول اضغط **انضم إلى المنصة** وسجّل طبيباً ← يظهر "حسابك بانتظار التوثيق" ولا يرى أي مريض.
2. ادخل بـ `admin` ← لوحة الإدارة ← **توثيق** ← ارجع لحساب الطبيب واضغط "تحقّق مجدداً" ← يدخل للوحة الطبيب.

### 7. المشرف
1. **المستخدمون**: إنشاء مستخدم، تعطيل حساب، تغيير كلمة مرور.
2. **دليل الأطباء**: إضافة طبيب غير مشترك (معلومات فقط) ← يظهر للمرضى بدون زر حجز؛ تخصيص ممرضين لطبيب.
3. **سجل العمليات**: من فتح سجل أي مريض ومتى.

### 8. التطبيق على الهاتف (PWA)
1. من **حسابي** ← **تفعيل الإشعارات** ← **عرض إشعار تجريبي**.
2. من قائمة المستخدم ← **تثبيت التطبيق** (Chrome / Edge).
3. جرّب اللغة الإنكليزية والوضع الداكن من الشريط العلوي.
4. على الهاتف الحقيقي يلزم HTTPS للتثبيت والإشعارات.
